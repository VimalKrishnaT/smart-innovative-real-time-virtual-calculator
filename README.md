# Smart Innovative Real-Time Virtual Calculator

## Overview
A computer vision-based virtual calculator project that explores touchless interaction through real-time hand tracking and gesture recognition.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## Key Concepts
- Real-time webcam video processing
- Hand landmark detection and tracking
- Gesture-based human-computer interaction
- Virtual interface interaction

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/smart-innovative-real-time-virtual-calculator.git
   cd smart-innovative-real-time-virtual-calculator
   ```

2. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

3. Activate the environment.

   Windows:
   ```bash
   venv\Scripts\activate
   ```

   macOS/Linux:
   ```bash
   source venv/bin/activate
   ```

4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the application using the actual entry-point file:

   ```bash
   python main.py
   ```

## Requirements
A webcam and a compatible Python environment are required.
